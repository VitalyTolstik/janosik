## Версионирование

Значимые изменения документируются здесь в стиле
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Версии следуют
[Semantic Versioning](https://semver.org/spec/v2.0.0.html). Релизы помечаются
в git как `v<version>` (например, `v0.1.0`), а образ контейнера публикуется в
`ghcr.io/vitalytolstik/janosik` из CI по тегу версии. Чтобы запустить
конкретный релиз, задайте `JANOSIK_TAG` в `.env` (см.
[Self-hosting](self-hosting/)).

## Unreleased

### Added

- Решения для self-hosting. Многоэтапный `Dockerfile` собирает SPA и API в
  единый образ, обслуживающий и то, и другое. Корневой `docker-compose.yml`
  поднимает app, PostgreSQL и Redis с healthcheck-ами и выполняет
  `prisma migrate deploy` при запуске. `.env.example` документирует каждую
  переменную. Образы публикуются в `ghcr.io` из CI по тегу версии.
- Укрепление self-host. `COOKIE_SECURE` с fail-fast защитой при запуске, чтобы
  production-установка по обычному HTTP отказывалась запускаться, а не молча
  отбрасывала refresh-cookie. `ALLOW_REGISTRATION`, плюс публичный
  `GET /auth/config`, который читает экран входа, чтобы скрыть регистрацию,
  когда она закрыта. Резервный вариант хранения `PURGE_AFTER_DAYS`. SSE
  утверждает `X-Accel-Buffering: no`, чтобы реальное время работало за nginx.
- Вложения файлов и аватары на локальном диске, со вставкой медиа,
  транскодированием видео в компактный MP4 и генерацией миниатюр изображений и
  постеров видео в фоне.
- Публичный общий доступ к доскам только для чтения, как замороженный снимок и
  как живой вид, с ограничениями частоты на токен, OG-превью и `?embed=1`.
- Панель администратора мастера по `/admin`: пользователи, доски, сущности,
  модерация, действия поддержки, флаги функций, операции и обслуживание,
  коммуникации и объявления, экспорт данных и соответствие требованиям,
  наблюдаемость, безопасность (TOTP 2FA и список разрешённых IP) и дашборд
  очередей Bull Board.
- Совместная работа: SSE в реальном времени, присутствие и атрибуция,
  комментарии с диффами истории и участники досок с ролями и истекающим
  доступом.
- Бэкенд: журнал команд с идемпотентностью и обработкой конфликтов, очереди
  BullMQ (mail, transcode, maintenance, media, exports, comms, demo), вход
  через OAuth (Google и Yandex), почтовые сценарии (подтверждение, смена,
  шаблоны) и fan-out через Redis для многоузлового реального времени.

## 0.1.0 - 2026-10-26

Первый релиз для self-hosting: offline-first PWA канбан-доска с
перетаскиванием, видами календаря и таблицы, отменой и повтором, лимитами WIP,
метками, чек-листами, ссылками, приоритетами, исполнителями, сроками,
i18n (английский и русский) и бэкендом на NestJS и PostgreSQL.
