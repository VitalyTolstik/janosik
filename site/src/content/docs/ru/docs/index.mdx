Janosik это self-hosted канбан. Доска это колонки с карточками, и каждое
изменение записывается командой, поэтому доску можно воспроизвести, откатить
и расшарить. Приложение работает либо как локальная PWA в браузере, либо
поверх бэкенда на NestJS с аккаунтами, realtime-обновлениями и публичными
ссылками на доску.

Документация состоит из четырёх частей.

## С чего начать

- [Начало работы](/ru/docs/getting-started/) запускает Janosik впервые, через
  Docker или из исходников.
- [Self-hosting](/ru/docs/self-hosting/) описывает compose-стек, HTTPS и
  полный справочник переменных окружения.
- [Операционные runbook-и](/ru/docs/runbooks/) описывают бэкап,
  восстановление, обновление, мониторинг и диагностику.

## Работа с приложением

- [Руководство пользователя](/ru/docs/user-guide/) описывает доски, колонки,
  карточки, виды, совместную работу, шаринг, поиск, аккаунт и оффлайн-режим.

## Администрирование платформы

- [Админ-панель](/ru/docs/admin/) описывает мастер-панель: пользователи,
  доски, контент, почта, безопасность и операции.

## Разработка поверх API

- [Справочник API](/ru/docs/api/) документирует HTTP API, включая
  [Command API](/ru/docs/api/commands/), которым управляют агенты и
  интеграции.
