Janosik — канбан-приложение для размещения на своём сервере. Доски состоят из
колонок и карточек. Изменения содержимого доски проходят через журнал команд и
поддерживают отмену; комментарии, вложения и управление доступом используют
отдельные REST-операции. Сервер на NestJS хранит данные в PostgreSQL и
предоставляет учётные записи, обновления в реальном времени и публичные ссылки.
Локальный режим без сервера используется только в модульных тестах.

Документация состоит из четырёх частей.

## С чего начать

- [Начало работы](/ru/docs/getting-started/) поможет впервые запустить Janosik через Docker или из исходников.
- [Установка на своём сервере](/ru/docs/self-hosting/) описывает compose-стек, HTTPS и
  полный справочник переменных окружения.
- [Инструкции по эксплуатации](/ru/docs/runbooks/) описывают бэкап,
  восстановление, обновление, мониторинг и диагностику.

## Работа с приложением

- [Руководство пользователя](/ru/docs/user-guide/) описывает доски, колонки,
  карточки, режимы просмотра, совместную работу, общий доступ, поиск, учётную запись и работу офлайн.

## Администрирование платформы

- [Админ-панель](/ru/docs/admin/) описывает мастер-панель: пользователи,
  доски, контент, почта, безопасность и операции.

## Интеграции и API

- [Справочник API](/ru/docs/api/) документирует HTTP API, включая
  [API команд](/ru/docs/api/commands/), которым управляют агенты и
  интеграции.
- [MCP-сервер](/ru/docs/mcp/) подключает доску к ИИ-агенту (Claude, Cursor,
  VS Code, opencode) по персональному API-ключу.

Ответы на частые вопросы собраны в [FAQ](/ru/docs/faq/). О защите приложения и
сообщении об уязвимостях читайте в [политике безопасности](/ru/docs/security/).

Эта документация описывает последний релиз. Когда появится вторая мажорная
версия, у каждой будут своя документация и переключатель в шапке.
