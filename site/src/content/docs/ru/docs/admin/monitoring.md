Раздел наблюдения отвечает на два вопроса: что происходит на платформе прямо
сейчас и что делали мастера и пользователи. Его покрывают четыре страницы:
дашборд, лента активности, журнал команд и журнал аудита.

## Дашборд

Дашборд это домашняя страница панели по адресу `/admin`. Он загружает два
запроса: `GET /admin/metrics` и небольшой `GET /admin/audit?limit=8`. Страница
состоит из трёх частей.

### Карточки статистики

| Карточка | Значение | Подсказка |
| --- | --- | --- |
| Пользователи | всего пользователей | `+N за 7 дней` |
| Заблокированы | пользователи с `disabledAt` | нет |
| Активные доски | доски не удалённые и не архивные | `N в архиве` |
| Активные карточки | карточки не удалённые и не архивные | `N в архиве` |
| Команды, 24ч | команды за последние 24 часа | `N за 7 дней` |
| Активные сессии | живые refresh-сессии | нет |
| Комментарии | комментарии не удалённые | нет |
| Мастер-аккаунты | всего мастеров | нет |

### Панель runtime

Панель runtime показывает четыре значения из `AdminMetricsDto.runtime`:

| Метка | Значение |
| --- | --- |
| Version | версия пакета backend |
| Uptime | время работы процесса, в формате `Nh Nm` или `Nm Ns` |
| Database | время обхода `SELECT 1`, в миллисекундах |
| Environment | `NODE_ENV` |

### Графики и недавний аудит

Два графика покрывают последние 14 дней, от старых к новым: регистрации за
день и команды за день. Ниже них находится `Recent admin actions`, последние
восемь строк аудита (действие, email мастера, время), со ссылкой на полный
журнал аудита.

## Лента активности

`/admin/activity` перечисляет изменения членства и события комментариев по
доскам. Подзаголовок: `Membership changes and comment events`.

| Колонка | Значение |
| --- | --- |
| Событие | `type` активности |
| Актор | email актора, со ссылкой на страницу пользователя |
| Доска | название доски, со ссылкой на страницу доски |
| Карточка | название карточки, со ссылкой на страницу карточки, или прочерк |
| Детали | payload события в виде JSON |
| Когда | время создания |

На странице есть поле поиска, вкладки периода (любое время, 24 часа, 7 дней,
30 дней) и постраничная навигация. Действий в строках нет.

## Журнал команд

`/admin/commands` перечисляет каждое действие доски по всем доскам, от новых к
старым. Подзаголовок: `Every board action, newest first`. Строки упорядочены по
времени создания, затем по номеру последовательности.

| Колонка | Значение |
| --- | --- |
| Действие | `type` команды |
| Актор | email актора, со ссылкой на страницу пользователя |
| Доска | название доски, со ссылкой на страницу доски |
| Seq | номер последовательности команды |
| Payload | payload команды в виде JSON |
| Когда | время создания |

На странице есть поле поиска, вкладки периода и постраничная навигация.
Действий в строках нет. Старый путь `/admin/log` перенаправляет на
`/admin/commands`.

## Журнал аудита

`/admin/audit` перечисляет действия мастеров в панели. Подзаголовок:
`{total} admin actions`.

| Колонка | Значение |
| --- | --- |
| Действие | имя действия аудита |
| Мастер | email мастера, со ссылкой на страницу мастеров, или копируется, когда мастер удалён |
| Цель | тип и id цели, или прочерк |
| Детали | payload аудита в виде JSON |
| Когда | время создания |

На странице есть поле поиска, вкладки периода и постраничная навигация.
Действий в строках нет.

### Действия аудита

Каждое действие, которое может нести журнал аудита:

| Группа | Действия |
| --- | --- |
| Аутентификация мастера | `admin.login`, `admin.login_failed`, `admin.login_locked`, `admin.logout`, `admin.sessions_revoked` |
| Управление мастерами | `admin.create`, `admin.disable`, `admin.enable`, `admin.unlock`, `admin.update`, `admin.password_changed`, `admin.password_reset`, `admin.owner_granted` |
| Пользователи | `user.create`, `user.update`, `user.email_changed`, `user.disable`, `user.enable`, `user.sessions_revoked`, `user.tokens_revoked`, `user.verified`, `user.unverified`, `user.verification_resent`, `user.password_reset`, `user.delete`, `user.impersonated`, `user.promoted`, `user.demoted` |
| Доски | `board.create`, `board.archive`, `board.unarchive`, `board.delete`, `board.command`, `board.member_added`, `board.member_removed`, `board.member_role_changed`, `board.owner_transferred` |
| Карточки и контент | `card.archive`, `card.unarchive`, `card.delete`, `attachment.delete`, `entity.restored`, `entity.bulk_deleted`, `comment.delete` |
| Сессии и токены | `session.revoke`, `token.revoke` |
| Почта | `email.settings_changed`, `email.test_sent`, `email.sent`, `email.template_changed`, `email.template_reset` |
| Конфигурация | `oauth.settings_changed`, `throttle.settings_changed`, `flag.changed`, `ops.settings_changed` |
| Коммуникации | `announcement.created`, `announcement.updated`, `announcement.deleted`, `comms.digest_sent`, `comms.reminder_sent` |
| Данные | `data.exported`, `data.export_queued`, `data.export_downloaded`, `retention.changed` |
| Безопасность | `security.totp_enabled`, `security.totp_disabled`, `security.ip_allowlist_changed` |
| Демо и ссылки | `demo.started`, `demo.stopped`, `share.created`, `share.refreshed`, `share.revoked` |
| Эксплуатация | `maintenance.run`, `queue.ticket_issued` |

## Общее поведение списков

Каждый список в панели использует одну реализацию таблицы, поэтому поведение
везде одинаковое. На каждой странице есть поле поиска, постраничная навигация и
фильтры, которые поддерживает её сущность.

- Вкладки статуса появляются только у сущностей с фильтром статуса (например,
  active, archived, deleted).
- Вкладки периода появляются только у лент по времени (активность, команды,
  сессии, токены, аудит): любое время, 24 часа, 7 дней, 30 дней.
- Постраничная навигация показывает всего, размер страницы и текущую страницу.
  Размер страницы по умолчанию 50, минимум 1 и максимум 100.
- На каждой странице есть индикатор загрузки, состояние ошибки с повтором и
  состояние пустоты.
- Неудачное действие показывает тост `Access denied` при `403`, `No connection
  to the server`, когда запрос не ушёл, и `The action failed` в остальных
  случаях.

Дашборд описан здесь; списки пользователей, досок и контента на своих
страницах: смотрите [пользователи и мастера](/ru/docs/admin/people/) и
[доски, карточки и контент](/ru/docs/admin/content/).
