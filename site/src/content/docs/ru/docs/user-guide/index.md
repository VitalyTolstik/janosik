Janosik — канбан-доска для планирования задач с помощью колонок и карточек. Это
руководство описывает экраны и элементы управления — от создания доски до
публичной ссылки только
для чтения.

![Вид доски: четыре колонки карточек с метками, сроками, приоритетами и аватарами исполнителей.](/screens/board.png)

## Два режима работы

- **Серверный режим** — доски хранятся в базе данных и доступны после входа. В
  этом режиме есть участники и роли, обновления в реальном времени, комментарии,
  вложения,
  публичные ссылки для чтения и личные API-ключи. Выпускаемая версия приложения работает в этом режиме.
- **Локальный режим** — режим без бэкенда, где доски живут в браузере. Он не
  входит в поставляемую сборку; он используется только в **модульных тестах**. Переносить
  данные между экземплярами Janosik всё равно можно через `Export JSON` и `Import JSON`.

Переключателя внутри приложения нет — режим задаётся сборкой. Руководство
описывает серверную версию. Названия кнопок и полей приведены для английского
интерфейса; язык приложения можно изменить в настройках учётной записи.

## Обзор интерфейса

### Шапка

Слева находятся элементы управления доской:

- логотип;
- **название доски** — щёлкните, чтобы переименовать;
- **переключатель досок** (шеврон) — ваши доски, новая доска и архив;
- **колокольчик** — приглашения на доски;
- кнопка **участников** — кто на доске и их роли;
- кнопка **общего доступа** — публичные ссылки для чтения (только
  администраторы).

Справа находятся инструменты:

- **Глобальный поиск** — поиск карточек и досок по всем доступным доскам (Ctrl/Cmd+K);
- **значок клавиатуры** — памятка по сочетаниям клавиш;
- **отмена / повтор**;
- **меню данных** — экспорт, импорт, резервные копии и архив карточек;
- ваша **учётная запись** — профиль, безопасность, API-ключи и настройки.

### Над колонками

- **Поле поиска** фильтрует карточки текущей доски; кнопка `Filters`
  открывает фасетные фильтры (срок, метки, приоритет, исполнитель, связи,
  дата создания).
- **Переключатель режимов просмотра**: `Board`, `Calendar`, `Table` или `Watch`.
- Меню **отображения** рядом с переключателем позволяет включить компактные
  карточки (`Simplify design`) и настроить прозрачность и размытие колонок в
  режиме доски.
