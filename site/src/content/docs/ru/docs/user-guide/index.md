Janosik это канбан-доска: упорядоченные колонки с карточками, которые вы
перетаскиваете, чтобы планировать работу. Это руководство проходит по каждому
экрану и элементу управления — от создания доски до публичной ссылки только
для чтения.

![Вид доски: четыре колонки карточек с метками, сроками, приоритетами и аватарами исполнителей.](/screens/board.png)

## Два режима работы

- **Локальный режим** — без сервера и входа. Каждая доска живёт в вашем
  браузере, и приложение полностью работает офлайн. Переносите данные между
  браузерами через `Export JSON` и `Import JSON`.
- **Серверный режим** — доски хранятся в базе данных за учётной записью.
  Добавляет участников и роли, обновления в реальном времени, комментарии,
  вложения файлов, публичные ссылки для чтения и личные API-ключи.

Режим задаётся сборкой; переключателя внутри приложения нет. Всё ниже
описывает серверный режим и отмечает, где локальный режим отличается.

## Обзор интерфейса

### Шапка

Слева всё про доску:

- логотип;
- **название доски** — щёлкните, чтобы переименовать;
- **переключатель досок** (шеврон) — ваши доски, новая доска и архив;
- **колокольчик** — приглашения на доски;
- кнопка **участников** — кто на доске и их роли;
- кнопка **общего доступа** — публичные ссылки для чтения (только
  администраторы).

Справа находятся инструменты:

- **Глобальный поиск** — карточки и доски везде (Ctrl/Cmd+K);
- **значок клавиатуры** — памятка по сочетаниям клавиш;
- **отмена / повтор**;
- **меню данных** — экспорт, импорт, резервные копии и архив карточек;
- ваша **учётная запись** — профиль, безопасность, API-ключи и настройки.

### Над колонками

- **Поле поиска** фильтрует карточки текущей доски; кнопка `Filters`
  открывает фасетные фильтры (срок, метки, приоритет, исполнитель, связи,
  дата создания).
- **Переключатель видов** выбирает, как рисуется доска: `Board`, `Calendar`
  или `Table`.
- Меню **вида колонок** (только в виде доски) задаёт прозрачность и размытие
  колонок.
