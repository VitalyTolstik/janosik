Сервер `@janosik/mcp` открывает доску любому MCP-клиенту (Claude, Cursor,
VS Code, opencode, Codex). Агент умеет перечислять доски, читать доску и
создавать, перемещать, комментировать, отмечать, назначать, связывать и
расшаривать карточки по персональному API-ключу. Записи идут через тот же
журнал команд, что и приложение, поэтому их можно откатить, и они видны
всем, кто смотрит доску, в реальном времени.

## Настройка

Создайте ключ в разделе **Аккаунт → API-ключи** (он начинается с `jnk_`) и
добавьте сервер в MCP-клиент:

```json
{
  "mcpServers": {
    "janosik": {
      "command": "npx",
      "args": ["-y", "@janosik/mcp"],
      "env": {
        "JANOSIK_URL": "https://boards.example.com",
        "JANOSIK_TOKEN": "jnk_…"
      }
    }
  }
}
```

`JANOSIK_URL` это источник вашего инстанса, `JANOSIK_TOKEN` это ключ. Оба
можно передать и флагами `--url` и `--token` (токен лучше задавать через
`env`: флаг виден в списке процессов). Добавьте `JANOSIK_APP_BASE`
(например `/app`), только если приложение живёт не в корне сайта; он нужен
для сборки ссылок на доску.

Загрузка и скачивание вложений, а также экспорт доски в файл трогают диск
машины, где запущен сервер, поэтому они выключены, пока не задан
`JANOSIK_MCP_ALLOW_FS=1`. Добавьте `JANOSIK_MCP_FS_ROOT=/path`, чтобы
ограничить их одним каталогом: симлинки за его пределы отклоняются, а
существующие файлы никогда не перезаписываются.

## Инструменты

Инструменты разбиты на группы. По умолчанию включены группы для работы с
доской: доски, колонки, карточки, метки, чек-листы, связи карточек,
комментарии, активность и вложения. Группы, которые меняют, кто видит доску,
или действуют от имени аккаунта (`members`, `invitations`, `shares`,
`account`), включаются явно:

| Настройка | Что делает |
| --- | --- |
| `JANOSIK_MCP_TOOLSETS` | Группы через запятую, например `default,members`, или `all`. |
| `JANOSIK_MCP_READONLY=1` | Только инструменты, которые ничего не меняют. |

У каждого инструмента данных есть `response_format`: `"markdown"` (по
умолчанию) или `"json"`. Имена всех инструментов начинаются с `janosik_`,
чтобы не конфликтовать с другими серверами.

Типичный прогон:

1. `janosik_list_boards` находит доску.
2. `janosik_get_board` читает колонки, карточки и метки (на большой доске
   передайте `columnId`).
3. Дальше точечные инструменты, например `janosik_create_card`, затем
   `janosik_move_card` и `janosik_add_comment`.

Запись, которая ничего не изменила (например, id нет на доске), возвращается
как ошибка, поэтому агент не примет её за успех. Инструменты, которые строят
запись по прочитанной доске, повторяют попытку, если другой агент успел её
изменить, а `janosik_update_card` принимает `expectedDescription`, чтобы
править общий текст, только если его никто не менял.

## Права

Ключ действует от имени создавшего его пользователя с теми же ролями: агент
видит только доски, где этот пользователь участник, редактирование требует
роли `MEMBER`, а управление участниками и ссылками требует `ADMIN`. Отзовите
ключ в панели аккаунта, чтобы отключить агента.

Текст карточек и комментарии пишут другие люди и агенты, поэтому всё, что
агент читает с доски, считайте недоверенным вводом. Дайте каждому агенту свой
аккаунт и ключ: в ленте активности будет видно, какой агент что сделал, а
отзыв одного ключа остановит одного агента.

Сервер открыт в репозитории, в каталоге `mcp/`; полный список инструментов в
его README.
