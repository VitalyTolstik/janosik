# Design and review artifacts

This directory holds design studies and review evidence. Only the Markdown
reports are tracked in git; prototype HTML and screenshot folders are local
artifacts. If a report links to `index.html` or `screenshots/`, those files
exist in the working copy but are not part of the repository.

Tracked reports:

- `admin-ui-study/MISSING-CONNECTIONS.md` — admin capability audit.
- `admin-connections-review/REVIEW.md` — verification of the admin audit.
- `project-gaps-review/REVIEW.md` — 18 product gaps outside the admin panel.
- `ui-roast/REVIEW.md` — live UI/UX teardown and table-stakes findings.
- `board-settings-redesign/REPORT.md` — Board Settings redesign study and
  implementation plan (direction 01, «Рельс доски»).

Local-only evidence:

- `board-settings-redesign/index.html` — self-contained interactive prototype.
- `board-settings-redesign/screenshots/` — prototype screenshots.
- `ui-roast/screenshots/` — 1440/1024/390 review screenshots.
- Other `design/*.html` and image explorations from earlier tasks.
