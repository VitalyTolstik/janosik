## Verification

- Backend typecheck, `npx tsc -b ui shared`, and Playwright typecheck.
- Focused UI Vitest run covering routing, settings/workflow, search, switcher, key handling, auth, notifications, admin navigation and locale catalogs. **219 tests passed in 23 files.**
- Shared Vitest suite. **542 tests passed.**
- Backend auth/OAuth Jest unit suites. **60 tests passed.** HTTP auth/OAuth e2e suites on a disposable PostgreSQL database. **22 tests passed.**
- Targeted Playwright Chrome runs against the current app at `/app/`, with a local backend and a separate disposable PostgreSQL database. **67 app tests and 19 admin tests passed.** Scenarios cover the acceptance cases, existing keyboard navigation, board and workflow operations, and admin navigation. A final 22-test app smoke reran auth, invitations, board settings and keyboard cases.
- The `/app/` production UI build and all seven bundle size budgets passed.
- Root lint, Prettier check and `git diff --check`. Lint reports warnings, with zero errors.

## Residual coverage

- ARIA roles, names, focus, active descendants and tab/panel links were verified in automated tests. Announcement behavior in NVDA, JAWS, VoiceOver and TalkBack remains unverified.
- The OAuth HTTP e2e uses provider stubs, and the short-screen verification test supplies an unverified registration response over a real local session. Live-provider callbacks and mail delivery were outside the verification run.
- Russian-layout tests inject the physical key code with the corresponding Cyrillic value. Short and mobile viewports were exercised in Chrome. OS input methods and physical devices were outside the run.
- The OAuth return cookie has a bounded payload and an allowlist for user-app routes. A rejected or expired destination falls back to the app root. Board Settings intentionally discards its open draft when the board changes. The admin editor asks before discarding.
