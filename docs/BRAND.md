# Janosik — бренд-гайд

Единый источник визуальной идентичности: позиционирование, тон, лого,
палитра, типографика, движение. Токены живут в `brand/` (`@janosik/brand`),
этот документ — их человекочитаемое описание.

## 1. Что это

**Janosik** — канбан-доска с локальным режимом и возможностью разместить её
на своём сервере. В локальном режиме доска работает в браузере и доступна
офлайн; серверная версия добавляет аккаунты, общие доски и синхронизацию
в реальном времени.

**Позиционирование (одной строкой):** «Kanban that feels crafted» —
продуманный канбан для команд и ИИ-агентов.

**Аудитория:** небольшие команды и самостоятельные специалисты, которым важны
приватность, контроль над данными и удобный интерфейс open-source-продукта.

**Чем отличаемся:** интерфейс и сервер применяют изменения через общий
редьюсер; поддерживаются отмена и повтор действий, совместная работа,
комментарии и вложения. Самостоятельную установку можно запустить командой
`docker compose up -d`.

## 2. Тон голоса

**Премиальный и спокойный.** Уверенно, без крика и маркетингового шума.

- Пишем по делу: короткие фразы, конкретные глаголы, ноль «революционных
  решений» и «инновационных платформ».
- Уважаем время читателя: заголовок сообщает суть, а не интригует.
- Тепло, но сдержанно. Юмор — редкий и сухой, не клоунада.
- Никогда не обещаем того, чего нет. «Работает офлайн» — значит работает.

| Так | Не так |
| --- | --- |
| «Boards that survive a dead Wi-Fi.» | «Revolutionary next-gen collaboration!» |
| «Undo that actually undoes.» | «Seamless synergy for your workflow.» |
| «Your data, your server.» | «Enterprise-grade cloud solution.» |

## 3. Лого

Основа — **«Перо Яношика»** (feather): знак, который несёт идею лёгкости,
точности и ремесла. В приложении перо анимировано (лёгкое покачивание, искра
при ховере) — это часть характера, а не декор.

Ассеты — в `brand/assets/logo/`:

| Файл | Назначение |
| --- | --- |
| `janosik-mark.svg` | Знак в градиентном тайле (иконка приложения, favicon) |
| `janosik-feather-dark.svg` | Тёмная версия пера — для светлых фонов |
| `janosik-feather-light.svg` | Светлая версия пера — для тёмных фонов |
| `janosik-lockup-dark.svg` / `-light.svg` | Знак и текстовый логотип |
| `janosik-wordmark-dark.svg` / `-light.svg` | Только текстовый логотип |

**Правила:**
- Не менять пропорции, не добавлять тени/обводки/градиенты к самому перу.
- Знак — только в градиентном тайле либо как одноцветное перо; не размещать
  перо на пёстром фоне без тайла.
- Тайл — синий бренд-градиент (`#2563eb → #38bdf8`), один и тот же в
  приложении и на сайте; фиолетовый в лого не используется.
- Свободное поле вокруг знака ≥ высоты пера.
- Минимальный размер знака в тайле — 24 px.

Конструкция и охранное поле — в `brand/assets/logo/janosik-construction.svg`
(сетка 24×24, радиус головки 6u, охранное поле 3u со всех сторон).

## 5. Типографика

Единственная гарнитура — **Space Grotesk**, подключённая локально через
`@fontsource`; используются начертания 500 и 700. Гарнитура применяется и в
заголовках, и в основном тексте. Длинные строки — не более 80 символов;
основному тексту задан увеличенный межстрочный интервал.

Токен: `--janosik-font-display`. Моно-стек используется только в коде/логах.

Шкала (`typeScale` / `--janosik-type-*`) задаёт размеры по ролям. Приложение
использует размеры Tailwind, сайт, документация и видео — эту шкалу:

| Роль | Размер | Межстрочный | Вес | Трекинг |
| --- | --- | --- | --- | --- |
| display | 4.5rem | 1.02 | 700 | −0.03em |
| h1 | 3rem | 1.1 | 700 | −0.03em |
| h2 | 2rem | 1.2 | 700 | −0.02em |
| h3 | 1.5rem | 1.3 | 700 | −0.01em |
| lead | 1.25rem | 1.6 | 500 | 0 |
| body | 1rem | 1.6 | 400 | 0 |
| small | 0.875rem | 1.5 | 500 | 0 |
| caption | 0.75rem | 1.4 | 500 | 0.02em |

## 6. Движение

Анимация поддерживает стиль интерфейса, но не мешает частым действиям.
Элементы, которыми пользуются постоянно, не анимируются.

- Кастомные кривые, не встроенные `ease`:
  `--janosik-ease-out` `cubic-bezier(0.23, 1, 0.32, 1)`,
  `--janosik-ease-in-out` `cubic-bezier(0.77, 0, 0.175, 1)`,
  `--janosik-ease-drawer` `cubic-bezier(0.32, 0.72, 0, 1)`.
- Длительности UI < 300 ms (`--janosik-duration-*`: 150/160/200/300 ms).
- Вход — из `scale(0.95)` + `opacity`, никогда из `scale(0)`.
- Ховер-анимации — только под `@media (hover: hover)`.
- При `prefers-reduced-motion` отключаем перемещение и масштабирование,
  сохраняя необходимые изменения цвета и прозрачности.

## 7. Арт-дирекшн (картинки сайта)

Визуальный стиль — светлый и сдержанный. Не использовать стоковые фотографии
людей и привычные техно-клише.

- **Палитра картинок:** белый/светло-голубой фон, синие акценты; мягкие
  градиенты `#2563eb → #38bdf8`; много воздуха (большие поля).
- **Сюжеты:** экраны продукта (доска, перетаскивание, совместная работа,
  вложения) показывать крупно, без фотографий «людей в офисе»; для фоновых
  секций использовать абстрактные голубые градиенты и сетки.
- **Обработка:** лёгкое затемнение под текстом, скруглённые окна-мокапы
  (browser chrome), тени мягкие; без неона и тяжёлых фильтров.
- **Чего избегать:** стоковых фото, роботов, пёстрых коллажей, фиолетового и
  розового, мелкого нечитаемого текста.
- Движение (клипы фич) — из `video/` (TASK-128), встраиваются как медиа
  (TASK-130); OG-шаблон — `brand/assets/og/janosik-og.svg`.

## 8. Реализация

- Токены: `brand/src/tokens.ts` (TS) и `brand/src/tokens.css` (CSS) —
  одна правда, парити-тест `brand/src/tokens.test.ts`.
- Приложение: `ui/src/index.css` импортирует `brand/src/tokens.css` и
  раздаёт их Tailwind-утилитам через `@theme inline`.
- Сайт и видео (TASK-123+) импортируют те же токены — расхождения быть не
  должно.
